Queue-governed merge path, operator transcript
==============================================
bin/fm-pr-merge.sh run against stubbed forge CLIs that behave like a real
GitHub repository whose base branch "main" is governed by a merge queue:
  * `gh-axi pr merge` with --squash/--merge/--rebase fails with GitHub's own
    refusal, "The merge strategy for main is set by the merge queue";
  * `gh-axi pr merge` with no strategy is accepted and (with --auto) enqueues;
  * `gh api .../rules/branches/main` returns the branch's merge_queue rule;
  * `gh api graphql` returns the pull request's live state/merged/isInMergeQueue.
Supervision-watcher banner lines ("WATCHER DOWN", unrelated to this change) are
filtered out of this transcript; nothing else is edited.
Harness: /tmp/fmq/transcript.sh (throwaway, outside the worktree).
